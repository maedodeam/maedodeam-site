P—02 · Real estate intelligence · Live, invite-only

DataBairro

  • Data engineering
  • ETL pipelines
  • PostGIS
  • Geospatial analysis
  • Statistical models
  • End-to-end

Real estate decisions backed by real data.

DataBairro is a real estate intelligence platform that estimates apartment market values in São Paulo using actual property transaction data rather than asking prices.

Built from the ground up, it transforms over 1.3 million property transaction records into actionable insights through geospatial analysis, automated data pipelines and statistical valuation models.

  • Data engineering. ETL pipelines download the city's public records, validate them, link each transaction to the property register and screen out sales that don't reflect the market.
  • 1.3 million+ records. 1,333,581 ITBI transaction records from 2019 to 2026, alongside the municipal property register.
  • Geospatial analysis. PostgreSQL and PostGIS place each address on the city's lot map and measure what's around it: transit, schools, health care and flood risk.
  • Comparable-based valuation. Up to eight comparable sales — same building first, then nearby — and the median price per square meter, applied to the unit's registered area.
  • Confidence indicators. Every estimate comes as a range with a confidence level. When the evidence is thin, DataBairro says so instead of guessing.
  • End-to-end development. From data pipelines and database to API, web app and production infrastructure.

03 / AboutThe person behind it

Built by experience. Driven by curiosity.

MAEDODEAM was founded by Roger Maedo, a software engineer with about twenty years of building systems that run in production.

Most of that time went into the hard, invisible parts: backends, architecture, integrations, distributed and enterprise systems — and leading the engineering behind them.

MAEDODEAM is where that experience gets to build things of its own: independent products, games, experiments, and collaborations on problems that are actually interesting.

Small on purpose. Fewer layers, more things that actually ship.
